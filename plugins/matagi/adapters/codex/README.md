# codex

`plugins/matagi/` を Codex CLI から使う変換・配線スクリプト置き場。

- `link-source-dirs.ts`: `skills/` 各スキルと `hooks/` → Codex 設定ルート（例: `.codex`）へ symlink。
- `generate-hooks-config.ts`: `plugin.json` の `hooks` → Codex 向け `config.toml` の `[[hooks.*]]` 変換（matcher = Codex ツール名に合わせ個別指定）。
- `generate-agents-toml.ts`: `agents/*.md` → Codex の `agents/<name>.toml` 変換。
- `toml.ts`: 上記共有 TOML 文字列シリアライザ。

いずれも `node --experimental-strip-types <script>.ts <出力先ディレクトリ>` 実行（`generate-hooks-config.ts` = 出力先に `config.toml` 既存なら失敗、上書き = `--force` 必要。`--force` = `config.toml` 全体置換、Codex 他設定も消える。`generate-agents-toml.ts` も内容異なる既存 `agents/<name>.toml` あれば何も書かず失敗、`--force` で上書き。同内容なら冪等。ソースから消えた古い生成物 = 先頭 `generated by` マーカーで識別可能なもののみ削除、ユーザー自作 `.toml` 削除なし。ソース `.md` 0件時 誤指定防止のため削除スキップ）。書込 = 一時ファイル経由 rename 置換、symlink / ハードリンクのリンク先書換なし。通常ファイルでも symlink でもない既存（ディレクトリ等）= `--force` でも拒否。生成物マーカー（先頭行）= 本 PR 同時導入のため既存生成物の移行手順不要。マーカー無し `.toml` = ユーザー自作とみなし削除なし。マーカー付き `.toml` = 編集しても再生成の上書き・削除対象（do not edit）。導入手順・前提事実・実機検証状況 → `plugins/matagi/documents/reference/multi-agent-support/codex-adapter.md` 参照。
