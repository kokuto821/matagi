# ページャーと件数カウンター
- 情報量が多い場合、ユーザーに見えている範囲を表示
  - ページャーで表示量を抑え、表示速度を速められる
## 原則
- 全体のボリュームがわかるようにする
  - 件数・並び順が見えると次の操作を考えやすい
- もっと見るボタン or 無限スクロールは使う場面を考える
  - シンプルな操作で簡単に扱える
  - SNS・チャット等、リアルタイムで情報が更新されるUIに向く
  - 「全体量がわからない」「画面遷移後に一覧画面に戻ってきたときに元の位置に戻りにくい」というデメリットあり
  - 一般的な一覧であればページャーを推奨
- チェックボックス一括選択に注意
  - 複数ページにまたがる要素をチェックボックスで一括選択した場合、「現在のページで選択したアイテム」だけが対象なのか、「全ページで選択したアイテム」が対象なのかがわかるようにする。
  - 「〇件選択中」、補足のテキストを入れる等
