# ページャーと件数カウンター
- 情報量多い場合、ユーザーに見えている範囲を表示
  - ページャーで表示量抑制→表示速度向上
## 原則
- 全体ボリュームがわかるようにする
  - 件数・並び順が見える→次の操作を考えやすい
- もっと見るボタン or 無限スクロールは使う場面を考える
  - シンプル操作で簡単に扱える
  - SNS・チャット等、リアルタイム情報更新UIに向く
  - 「全体量がわからない」「画面遷移後に一覧画面に戻ってきたとき元の位置に戻りにくい」デメリットあり
  - 一般的な一覧→ページャーを推奨
- チェックボックス一括選択に注意
  - 複数ページにまたがる要素をチェックボックス一括選択した場合、「現在のページで選択したアイテム」のみ対象か「全ページで選択したアイテム」対象かわかるようにする
  - 「〇件選択中」、補足テキストを入れる等
