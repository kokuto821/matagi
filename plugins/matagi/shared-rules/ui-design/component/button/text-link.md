# text-link
- <a>に該当するパーツ
- 画面遷移、外部サイトへのリンク
- 文章内の補足・引用元を示す
## 性質
- 下線でテキストリンクと認識されやすい。
  - 画面内に多数のテキストリンクが登場する場合
- 下線が多くあると複雑な印象を与えて印象になる
  - 対策: 初期状態は文字色変更、オンマウス時のみ下線表示。リンクと示しつつ複雑な印象を弱められる
## 原則
- ボタンより存在感控えめ・目立ちにくい。画面内で重要度・優先度の低いものに利用
- 外部リンク等にはアイコンをつける
  - 押した後の挙動をわかりやすく伝えられる
  - 「外部のサイトにリンクする」「新規ウィンドウでページが開く」「メールが起動する」等
- リンクテキストの内容
  - ×詳細はこちら
    - リンク先の内容が明確に伝わらない
  - 〇リンク先の画面名を明示
  - ユーザーに伝わりやすい名称になっている
