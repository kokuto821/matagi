# モーダル
- ユーザーに意思決定を促す場面、重要な一つの操作に集中させるため利用
## 原則
- 特定操作→画面暗転、中央にウィンドウ表示
  - 誤操作なくしユーザー安心利用のための必須パーツ
- モーダル下部に意思決定ボタン表示
  - 意思決定の文言は具体的に
  - 「データを送信しますか？」
    - 〇「送信する/送信しない」
    - ×「はい/いいえ」
- 紛らわしい表現を避ける
  - 予約取り消し操作をモーダル実行時、「キャンセル」「取り消し」記載→同じ言葉が並び誤解を与える
  - 〇「予約したままにする」「予約を取り消す」
- 複雑操作を分割して簡単に見せる
  - 画面内に複雑操作あり→モーダルで一部操作を切り出せる
  - 操作を理解しやすい画面になる
  - 複雑な作業工程がある画面→モーダル化を検討
- モーダルダイアログ重ねて表示しない
  - ×モーダルダイアログ内でさらにモーダルダイアログを開く
- ダイアログを結果表示に使う
  - ユーザーに確実に気づいてもらえるが、ユーザー操作を止める
  - 使用は必要最低限。結果表示はトースト・メッセージ等で行う
- キャンセルOKの順番
  - Windowsでは「OK」→「キャンセル」
  - iPhoneでは「キャンセル」→「OK」
  - 複数プラットフォーム・明確なルールなき限り、人間の心理的視線誘導に従い「キャンセル」→「OK」の順
