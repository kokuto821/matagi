# モーダル
- ユーザーに意思決定を促す場面で、重要な一つの操作に集中させるため利用
## 原則
- 特定の操作をすると、画面が暗転し、中央にウィンドウを表示。
  - 誤操作を無くしユーザーが安心して利用するための必須パーツ
- モーダル下部に意思決定ボタンを表示
  - 意思決定の文言は具体的に
  - 「データを送信しますか？」
    - 〇「送信する/送信しない」
    - ×「はい/いいえ」
- 紛らわしい表現を避ける
  - 予約取り消しの操作をモーダルで実行するとき、「キャンセル」「取り消し」と記載すると同じ言葉が並び誤解を与える。
  - 〇「予約したままにする」「予約を取り消す」
- 複雑な操作を分割して簡単に見せる
  - 画面内に複雑な操作がある場合、モーダルで一部の操作を切り出せる
  - 操作を理解しやすい画面になる
  - 複雑な作業工程がある画面ではモーダル化を検討
- モーダルダイアログを重ねて表示しない
  - ×モーダルダイアログ内でさらにモーダルダイアログを開く
- ダイアログを結果表示に使う
  - ユーザーに確実に気づいてもらえるが、ユーザーの操作を止める
  - 使用は必要最低限。結果表示はトーストやメッセージ等で行う
- キャンセルOKの順番
  - Windowsでは「OK」→「キャンセル」
  - iPhoneでは「キャンセル」→「OK」
  - 複数プラットフォームや明確なルールがない限り、人間の心理的視線誘導に従い「キャンセル」→「OK」の順にする
