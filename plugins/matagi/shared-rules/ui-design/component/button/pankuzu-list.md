# パンくずリスト
- アプリ内で今いる画面の到達経路・所属カテゴリを把握できるパーツ
- 1つ前・2つ前の操作に戻りたい場合に便利なパーツ
## 原則
- 画面数の多いサイト・マニュアルページでは利便性が高いため必ず置く
- 階層が浅いアプリであれば、不要
  - ナビゲーションにカレントがあれば現在地を理解可能なため
- 画面タイトル・ナビゲーション・パンくずリストの文言は必ずそろえる
  - 同じオブジェクトを指すと明確に伝わり、画面の導線・アプリ内構成がわかりやすくなる
- パンくずリストにリンクを設置し、上位階層の画面に戻れるようにする
- 現在地とリンクをわかりやすくする
  - 末尾の現在地はクリック不可・太字
  - 前階層は下線を引く
