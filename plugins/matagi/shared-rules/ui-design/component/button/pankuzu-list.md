# パンくずリスト
- アプリ内で今いる画面の到達経路・所属カテゴリを把握できるパーツ
- 1つ前・2つ前の操作に戻りたい場合に便利なパーツ
## 原則
- 画面数多いサイト・マニュアルページ→利便性高いため必ず置く
- 階層浅いアプリ→不要
  - ナビゲーションにカレントあれば現在地を理解可能なため
- 画面タイトル・ナビゲーション・パンくずリストの文言は必ずそろえる
  - 同じオブジェクトを指すと明確に伝わる→画面導線・アプリ内構成がわかりやすい
- パンくずリストにリンク設置→上位階層の画面に戻れるようにする
- 現在地とリンクをわかりやすくする
  - 末尾の現在地=クリック不可・太字
  - 前階層=下線
