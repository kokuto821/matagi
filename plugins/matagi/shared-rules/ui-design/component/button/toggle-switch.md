# トグルボタンとスイッチ
- トグルボタンとスイッチ: 状態切り替え用
- 設定画面・モード切り替えで使用
## 原則
- トグルボタン
  - 複数状態を表す
  - 押下で別状態に切替
  - 異なる状態・機能の切替
  - タブのように利用可
  - オン/オフの2状態切り替えにも使用可
    - ただしスイッチよりスペースを取る
  - フリップフロップ問題
    - 現在状態か押下後状態か判別できない問題
    - オンオフが視覚的に明確になるよう、ラベル付きボタンを左右に並べる
- スイッチ
  - オン/オフの2状態を切替
  - トグルボタンより即時性が高い
    - 機能の有効化/無効化が即座に伝わる
- チェックボックス
  - スイッチ同様、オン/オフの2状態を切替
  - 即時有効化の場合と、保存しないと有効化されない場合がある
