# トースト
- ユーザー操作のフィードバックとして用いる
- 表示後しばらくして自動で非表示になるため、操作を中断しない
## 原則
- 表示内容は成功を表す短いテキスト。
- エラーはユーザーが読む必要があるため、自動で消えるトーストは不適
- ユーザーが気づきやすい場所に表示する
  - 直前の操作ボタン付近か画面上部に表示するのが一般的
  - モバイルは画面下部に操作ボタンがあるため、下からトーストを出すことが多い
- トーストとメッセージアラートのSuccessはほぼ同じ
  - トーストは自動で消えるが、アラートはユーザーが自分で消す必要あり
## 例
- 保存しました
- 送信しました
