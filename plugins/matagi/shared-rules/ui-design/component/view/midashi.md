# 見出し
- 直後のコンテンツのタイトル・要約等を表記するテキスト
## 原則
- デザイン作成時のパーツはh2以降を用意
  - h1は画面タイトルとしてページヘッダーに記載する場合が大半のため
- 大きい見出しから順に小さい見出しを使い、情報の階層をわかりやすく整理
  - 〇 h2→h3→h4
  - × h3→h2
  - ナビゲーションによってh2の見た目を複数用意してパターン整理する等、直後のコンテンツの大きさに合わせた見出しの見た目を考えることも重要
- Webサイトは見出しで目を引く必要があるため、大きい文字サイズ・色・装飾を工夫し、デザイン性を高める
- アプリケーションは見出しの文字を小さく、色も黒・グレーで控えめにし、機能の操作部分を強調する必要がある。
