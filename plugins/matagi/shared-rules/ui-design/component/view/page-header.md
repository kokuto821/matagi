# PageHeader
- アプリ全体ヘッダーとは別の画面単位ヘッダー
## 原則
- 必須
  - 画面タイトルを記載
  - 前の階層に戻るためのボタンを配置
    - パンくずリスト or 単純な戻るボタンを左端に配置するのが一般的
    - ユーザーの現在地把握に役立つ
- 任意
  - その画面全体にかかる機能を配置
    - 現在の画面の表示対象を操作するボタンを置く
    - アプリ全体でページヘッダーに画面毎機能を配置→一貫性が生まれ迷わず操作できる
    - スペース不足ならドロップダウンメニューを用いる
## 例
- 例：投稿レシピ一覧ページ
  - 画面タイトル
  - 検索
  - 投稿ボタン
- 例：オムライスのレシピ
  - レシピ編集
  - レシピ削除
  - レシピを共有
