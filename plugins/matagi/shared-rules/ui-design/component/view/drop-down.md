# ドロップダウンメニュー
- クリックで複数操作メニューがリスト状に展開する機能
  - 操作が多くレイアウトが収まらないときに使用
  - 多数ボタンをコンパクトに整理
## 原則
- ボタン右側に下矢印を置き、そのボタンから派生・関連する機能をメニューとして並べる
- 操作が多くレイアウトに収まらない場合に使用
- ボタンの優先度を弱めたいときに使用
  - ドロップダウン=メニューを開く→操作メニューを押す 2段階操作
  - 通常ボタンより操作負荷が高い
- コンテキストメニューは使わない
  - Webブラウザでは右クリック操作の印象が薄い→コンテキストメニューと同役割のメニューは「...」で表示
## 例
- 「メール送信」のボタンから「予約送信日時」を選択する
- 「削除」等ユーザーにあまりさせたくない操作→メニュー1件だけでもあえてドロップダウンメニュー内に配置する手法もある
