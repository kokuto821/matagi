# ドロップダウンメニュー
- クリックで複数の操作メニューがリスト状に展開する機能
  - 操作が多くレイアウトが収まらないときに使用
  - 多数のボタンをコンパクトに整理
## 原則
- ボタンの右側に下矢印を置き、そのボタンから派生・関連する機能をメニューとして並べる。
- 操作が多くレイアウトに収まらない場合に使用
- ボタンの優先度を弱めたいときに使用
  - ドロップダウンは、メニューを開く→操作メニューを押すという2段階の操作になる
  - 通常のボタンより操作負荷が高い
- コンテキストメニューは使わない
  - Webブラウザでは右クリックで操作する印象が薄いため、コンテキストメニューに同様の役割のメニューは「...」で表示する
## 例
- 「メール送信」のボタンから「予約送信日時」を選択する
- 「削除」等、ユーザーにあまりさせたくない操作は、メニューが1件だけでもあえてドロップダウンメニュー内に配置する手法もある
