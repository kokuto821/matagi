# PCアプリのナビゲーション
## 原則
- ナビゲーションはヘッダー or 左サイドバーに配置
  - ヘッダーはToC向け消費者サイト等、レスポンシブ設計のサイトでよく見られる
  - 左サイドバーは業務系アプリで多用。縦スクロール可で多くの情報を載せられる
- カレント状態を必ず用意する
  - 現在地をユーザーに示し、迷わせないUIにするため
- ナビゲーションの階層化・入れ子構造
  - 親子関係がわかるよう、レイアウト・強弱を工夫
  - 例
    - 親ヘッダーでカテゴリを示し、子のサイドナビゲーションでカテゴリ内の現在位置を明確にする
    - 親のサイドナビゲーションに色を敷いて画面左側に配置し、子のサイドナビゲーションは右側に配置して階層関係を明確にする
- メニュー数を多くしすぎない
  - 多すぎるとできることを確認しきれず迷うため
  - 目安: メニュー数7個以内
    - どうしても減らせない場合はドロップダウン等でナビゲーションを階層化
