# 定義リスト
- データ情報を画面表示するリスト

## 原則
- 項目名と値をセットで表示
- 縦並びの定義リスト
  - メリット
    - 画面幅が狭い場所、特にモバイルに適す
    - デスクトップでは複数個並べても見やすい
  - デメリット
    - 横並びより高さが出やすい
      - 項目数が多いとページが長くなる
- 横並びの定義リスト
  - メリット
    - 縦方向にコンパクト化可、デスクトップアプリのレイアウトに適す
    - 2列で表のような形になり、1対1の関係がわかりやすい
  - デメリット
    - 画面幅が狭い場所では使いにくい
      - モバイルでは適さない
- 入力画面とレイアウトをそろえる
  - 設定画面・フォーム等でユーザー入力データ表示に適す
