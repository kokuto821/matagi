# ステータスラベルとチップ
- ステータスラベルは状態表示に使用
  - オブジェクト状態を強調し視覚的マークとして認識しやすくする
  - 「発送中」「配達済み」「完了」「中止」
- チップは関連する補足情報・属性をシンプルに伝えられる
  - 検索用タグとして用語をチップで表現
## 原則
- ラベルで現在状況を一目瞭然にできる
  - 赤色のラベル
    - 「エラー」「緊急」
  - グレーのラベル
    - 「完了」「非アクティブ」
  - 使用色は絞り込みアプリケーションで一貫したルールを設ける
    - 赤＝エラー
    - 緑＝成功
    - 青＝情報
    - 多数の似た色→ユーザー混乱
  - 状態以外にカテゴリ分類にも使用される場合あり
    - 「重要なお知らせ」「メンテナンスのお知らせ」
- チップは情報を並列に扱える
  - タグ・キーワード表示、選択項目の列挙、フィルター条件表示
  - 色や装飾も控えめ
    - 複数並べても整然とした印象を与えられる
  - 情報を読み取りやすい、比較が容易
