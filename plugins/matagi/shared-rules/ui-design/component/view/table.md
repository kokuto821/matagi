# table
- 表形式でデータ表示
  - リスト・カードより情報が均一に見える
  - テキストが整理されて並ぶため見やすい
  - 見出しで列ごとにソート可能
  - 列の並び替えができる
## 原則
- 特にデスクトップアプリでは、リスト・カード同様アイテムを並べる際に用いる
- 極力横スクロールは避ける
  - 閲覧負荷を高めるため 
    - 情報が隠れる
    - 右端にあるボタンが押せなくなる
- 列数削減・改行なしで見やすくする
  - 一定幅超過→末尾に「...」を置き省略表示を推奨
- テーブル特有の機能を活かす
  - 列名をクリックしてソート
  - 左上のチェックボックスで一括チェック
  - 特定の列の色を変える・強調する
