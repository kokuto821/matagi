# ステッパー
- 複数ステップに分かれた工程を示すパーツ
  - ページが分かれた入力フォーム・プロセスフローで使用
    - 会員登録
    - オンライン購入の手続き
  - 進捗を視覚的に伝え、次にすべきことを明確にする
  - 入力途中の離脱を防ぐ役割
  - 全体の流れを直観的に理解
## 原則
- 全体の流れを明確に示す
  - 進捗状況が正確に表示される
- 画面幅が狭いデバイスでは横並びステップが収まりきらない場合がある
  - スライド可能なデザイン、または分数表記を検討
  - 3~6ステップでは全体の流れを示す矢印を追加し、完了までの距離感を図で視覚的に伝える
  - 7~の長い工程では分数表記も有効
