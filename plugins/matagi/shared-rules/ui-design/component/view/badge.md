# badge
- 項目に特定状態・数値を付与しユーザに通知するパーツ
## 原則
- バッジを消したい心理に働きかける
  - 未読メッセージ・要アクション項目を目立たせ、迅速対応を促せる
- バッジを消すアクションを明確に伝える
  - 何をしたらバッジが消えるのか
  - 消し方不明→ユーザーは強いストレス→わかりやすい設計にする
- バッジは本当に必要な箇所のみにつける
  - 必要以上につけると本来の役目「注意を引く」効果が失われる
## 例
- 通知バッジが未読メッセージを示す場合、遷移先ページで未読/既読を明確に区別できるデザインを用意
- 未完了タスクを示すバッジの場合、未入力項目・達成すべきアクションを明確に示すデザインを用意→ユーザーは次の行動を直観的に予想しやすい
