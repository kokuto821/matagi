# badge
- 項目に特定の状態・数値を付与し、ユーザに通知するパーツ
## 原則
- バッジを消したい心理に働きかける
  - 未読メッセージ・要アクション項目を目立たせ、迅速な対応を促せる
- バッジを消すアクションを明確に伝える
  - 何をしたらバッジが消えるのか
  - 消し方がわからないとユーザーは強いストレスを抱えるため、わかりやすい設計にする
- バッジは本当に必要な箇所だけにつける
  - 必要以上につけると本来の役目「注意を引く」効果が失われる
## 例
- 通知バッジが未読メッセージを示す場合、遷移先ページで未読と既読を明確に区別できるデザインを用意
- 未完了タスクを示すバッジの場合、未入力項目・達成すべきアクションを明確に示すデザインを用意すれば、ユーザーは次の行動を直観的に予想しやすい。
