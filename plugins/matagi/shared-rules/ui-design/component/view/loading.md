# loading
- システム処理中を伝える
  - 待ち時間ストレス軽減
## 例 
- 回転、点滅、プログレスバー
- キャラクターやイラストを動かしたアニメーション
  - アプリの世界観構築やブランディング
- 画面全体を暗転させるローディング
  - 中央にローディング
  - 汎用性が高い
  - どの画面でも使える
  - 画面全体の処理が完了するまでほかの操作が行えない状況に〇
  - ユーザーが次のアクションを起こす前に処理を終わらせる必要がある場合〇
- 画面の一部だけにローディング
  - 操作を中断させず処理状況を伝える〇
- スケルトンローダーの活用
  - 画像・リスト・テキスト等の読み込み中パーツをシルエットやグレーのラインで表現し、データ表示までの間、画面全体を視覚的に提示する方法
  - 次に表示される内容を予測しやすい、待ち時間を短く感じる効果
  - デザインに違和感なく組み込める
  - 一覧表示やカード型デザインに向いている
