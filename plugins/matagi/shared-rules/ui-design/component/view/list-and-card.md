# リストとカード
- 一覧画面に複数の画面が並ぶ
  - 一覧からアイテム選択→何かしらの操作を行うのが一般的
## 原則
- リスト・カードは情報を見つけやすいようシンプルに
  - 見つけやすさを優先
- 縦一列に並ぶリストビュー
  - アイテムを多く並べられる
  - 文字情報メイン
  - 高さを抑えられる
  - アコーディオンに派生可能
- 複数列でカードが並ぶグリッドビューあり
  - カード型で画像を大きく見せられる
  - リストビューより直観的に探せる
- リストとグリッドの切り替えを可能にする
  - トグルボタンを置きユーザー好みで選択可能に→一人ひとりに合わせたUIにできる
- ソートにはセレクトボックスを用いる
