# リストとカード
- 一覧画面に複数の画面が並ぶ
  - 一覧からアイテムを選択して、何かしらの操作を行うことが一般的
## 原則
- リストやカードは情報を見つけやすいようシンプルにする
  - 見つけやすさを優先する
- 縦一列に並ぶリストビュー
  - アイテムを多く並べられる
  - 文字情報メイン
  - 高さを抑えられる
  - アコーディオンに派生可能
- 複数列でカードが並ぶグリッドビューがある
  - カード型で画像を大きく見せられる
  - リストビューより直観的に探せる
- リストとグリッドの切り替えを可能にする
  - トグルボタンを置き、ユーザー好みで選択可能にし、一人ひとりに合わせたUIにできる
- ソートにはセレクトボックスを用いる
