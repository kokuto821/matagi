# メッセージアラート
- ほかの要素より目立たせ、ユーザーに情報を伝えるパーツ
## 原則
- 一般的に以下の4種類を使用
  - Information
    - 青
  - Success
    - 緑
  - Warning
    - 黄色
  - Danger
    - 赤
- お知らせとして使うアラートとフィードバックとして使うアラートを分ける
  - お知らせ
    - 画面上に最初から表示。システムからのお知らせ・操作上の注意点を記載
    - 押下で詳細情報を確認できるリンクにする場合もある
  - フィードバック
    - ユーザー操作への回答として表示
    - 実行操作後に「成功」「失敗」を表示
