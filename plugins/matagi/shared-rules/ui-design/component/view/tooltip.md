# tooltip
- アイコン・ボタン等の要素にカーソルを合わせて表示される小さなポップアップ
  - PC画面で補足情報・操作方法を伝えるために使用
  - 初めて使う機能・わかりにくい要素の補足にも有効
## 原則
- オンマウス表示のツールチップは簡潔に情報提供
  - 多用はしない
  - ユーザーが疑問に思う可能性が高い要素に補足情報を簡潔に伝えられる
  - 意味が曖昧なアイコン・操作結果がわかりにくいボタンに効果的
  - わかりやすい要素にはツールチップ不要
- ツールチップ内情報量は必要最低限に抑える
- 省略された文字を補完する
  - メールタイトル等、レイアウト上の都合で文字省略された場合、全文表示が有効
  - 表示エリアに注意して設計
- クリック・タップで表示する補足説明のツールチップ
  - 固有名詞・専門用語・入力欄の補足説明で有用
  - 項目付近に「？」アイコン・情報アイコンを設置しクリックさせる仕組み
    - 長い説明を表示する場合に有効
    - 正方形に近い形状を用意、詳細はリンクを張る
    - 閉じるボタンを右下に置く
