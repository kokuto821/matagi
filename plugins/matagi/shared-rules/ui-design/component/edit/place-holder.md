# プレースホルダー
- 入力値が空のとき、薄い文章でテキスト表示→ユーザー文字入力をサポート
  - 細かいがアプリの使い勝手を大幅向上できる
## 原則
- 入力例を記載する
- 項目名を記載してコンパクトに
  - 項目名をインプットに入れる→外側に項目名を置く必要なし
- 検索ボックスでは検索可能キーワードを記載
  - 検索対象を事前に知らせられる
  - 複数の検索キーがある場合におすすめ
  - 入力後に項目名がわからなくなる点に注意
- 入力時の注意はプレースホルダーに記載しない
  - 入力開始後は確認できなくなるため
  - 該当する場合は入力ボックスの外に記載

## 例
- 入力例を記載
- 入力項目名自体を記載
- 「漢字」と「かな」の入力欄があった場合
  - 「山田」「太郎」「やまだ」「たろう」と入力されている
- 数字の場合は桁数をあらかじめ表現
