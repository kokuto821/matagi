# input
- 押下で選択状態、キーボード操作で文字入力可
## 原則
- インプットは基本的に1行入力時に使う
  - 改行含む複数行は「テキストエリア」を使う
- 入力内容と画面全体レイアウトのバランスを見て、ちょうど良い落としどころを探る
  - 入力内容で幅を調整
    - 入力前に文字長さを想像させ、スムーズに操作を進められる
  - 画面全体のレイアウトバランスも考慮
    - モバイルでは幅いっぱいが良い場合もある
    - デスクトップでも幅をそろえて整列→見やすいレイアウトにできる
- 参照画面は登録画面と同じ見た目にしない
  - 入力可能と誤認される
    - disableであっても同様
  - 参照画面では通常テキスト（定義リスト）を置き、確定データとわかるようにする
