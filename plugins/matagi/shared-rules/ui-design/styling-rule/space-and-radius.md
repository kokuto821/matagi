# 余白と角丸
- 余白で高機能アプリ/簡単そうアプリの見せ方を調整可
- 業務用のアプリ
  - 情報多量→余白を狭くする
  - 高機能で複雑
- 幅広いユーザーが使う場合
  - 余白を広くする
  - 簡単なイメージ
  - スクロールや画面遷移が多くなる
- 角
  - 四角寄り
    - 安定
    - 情報を多く配置したい場合
  - 丸み
    - 優しい
    - 先進的
    - ボタンやカードは角丸

## CSS
| 用途                     | クラス      |
|--------------------------|------------|
| ボタン・入力欄・カード     | rounded-lg  |
| タグ・バッジ              | rounded-full|
| モーダル・ドロワー         | rounded-xl  |
| 原則それ以外は使わない     | —           |

- rounded-sm / rounded-md / rounded-3xl 等は禁止
- 「とりあえずrounded」（= rounded-md相当）も禁止。必ず用途対応クラスを選ぶ
- 要素の内側の角丸は少し小さくする
  - 角丸内にさらに角丸を置く場合、半径に同じ値を設定→バランスが悪く見える
  - 間の余白分、外側の角丸値を大きくする
    - 外と内の間が4pxの場合、外側は内側より4px大きくする
