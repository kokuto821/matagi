# 配色
## 配色の役割
- primary
  - サイト・アプリのトーン＆マナーを決定づける色
  - ブランドやテーマの反映
  - ロゴ・ヘッダー、ナビゲーションパーツ、CTA(行動喚起)ボタンに使われる
  - 背景色
- secondary
  - 情報整理
  - 優先順位の明確化
  - 副導線ボタンやセクション区切り
  - 補助的な要素
- accent
  - ユーザーの目を引く
  - 重要な情報
  - CTA
  - 通知
  - エラーメッセージ
  - 限定的な使用
## 配色の割合
- 70%
  - baseColor
  - 画面の大部分、モノトーン系、淡いパステル系の色 
- 25%
  - mainColor
  - ユーザーの目に留まる要素
    - デザイン全体のブランド・印象・テーマを理解するガイド
    - UIの主要なボタンや重要な見出し
- 5%
  - accentColor
  - 緊急性や特別感
    - エラー表示の赤
    - セール情報の黄色

## コントラスト比
- primaryやsecondaryを文字色に使う場合、背景とのコントラスト比は「4.5:1」（文字色24px以上は3:1）
