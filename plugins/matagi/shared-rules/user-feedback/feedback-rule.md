# ユーザーフィードバックのルール化

## 原則

ユーザーから指摘・訂正・改善提案を受けたとき、繰り返し発生しうるパターンならルール化を検討。

## 判断基準

以下いずれか該当する場合、ルール化を提案または実施:

- 同じ誤りを再び犯す可能性あり
- 判断の軸になる原則として明文化可能
- 既存ルールの抜け穴・例外を埋める内容

一度限りのコンテキスト固有の指摘はルール化しない。

## 手順

1. 指摘内容を受け取る
2. 上記判断基準に照らす
3. ルール化すべきと判断したら、適切なトピックの `rules/<topic>/` への追記または新規作成を提案
4. ユーザー承認を得てから書き込む
