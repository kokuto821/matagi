# README 配置ルール

## 目的

リポジトリ内の全ディレクトリに、その場所が「何を置く場所か」を人間が一目で理解できる `README.md` を必ず置く。AI 向けの `SKILL.md` / `*-rule.md` とは別の、**人間の読み手のための入口**として機能させる。

## 必須化のルール

**`.git/` を除く全ディレクトリに `README.md` を必ず置く。**

- 新規ディレクトリ作成時は、同じコミットで `README.md` も追加。
- スキルディレクトリ（`SKILL.md` がある）や設定系ディレクトリ（`.claude/`, `.claude-plugin/`）も例外ではない。`SKILL.md` は AI/ハーネス向け、`README.md` は人間向けと役割を分ける。
- リポジトリルートも対象。ルートの `AGENTS.md`（AI 向け）とは別に、人間向け `README.md` を置く。

唯一の例外: `.git/` 配下。

## 書き方

- **読み手は人間**。AI 向け指示でなく、「このディレクトリに何があり、何のために存在するか」を平易に書く。
- 短くてよい（1〜数行）。ディレクトリの役割・置くもの・置かないものが分かれば十分。
- 必要に応じて配下の主要サブディレクトリ／ファイルへの簡単な索引を添える。
- 詳細なポリシー・手順は対応する `rules/` や `SKILL.md` に書き、README からは参照に留める（重複させない）。

## よくある誤り

- ❌ 新規ディレクトリ作成後に `README.md` を置き忘れる
- ❌ README に AI 向け指示や詳細手順を書き込む（人間向けの概要に留める）
- ✅ ディレクトリ作成と同時に、人間向けの短い `README.md` を添える
