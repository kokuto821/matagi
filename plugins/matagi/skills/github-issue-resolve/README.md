# github-issue-resolve

issue 駆動開発**実行フェーズ**担当スキル。既存 issue を1件選び、ブランチ作成 → 実装方針合意 → 実装 → セルフレビュー → PR 作成 → issue クローズまで一気通貫。PR のマージはユーザーが行う。

実装・レビュー中身 = 既存スキル（`tdd` / `coding` / `coding-review` など）へ委譲。本スキル自身 = フェーズ進行・GitHub 操作のみ担当。

定義 = `SKILL.md`、判断基準 = `shared-rules/issue-driven-development/issue-driven-rule.md` 参照。issue を新規作る**作成フェーズ** = `skills/github-issue-create/`。
