# github-issue-create

issue 駆動開発**作成フェーズ**担当スキル。issue 化すべきか判断→定型フォーマット（概要 / 背景・目的・再現手順 / 要件 / 対応方針）で GitHub issue 本文組み立て→承認取得後 `gh` CLI で issue 作成。

定義 = `SKILL.md`、issue 本文雛形 = `reference/`、判断基準 = `shared-rules/issue-driven-development/issue-driven-rule.md` 参照。作成した issue を実装から PR 作成・issue クローズまで進める**実行フェーズ** = `skills/github-issue-resolve/`（PR のマージはユーザーが行う）。
