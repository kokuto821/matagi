# ドキュメント文体ルール

## 原則

**本リポジトリ（`matagi` / `matagi-kaji`）の `.md` 生成・編集は genshijin 通常レベルで書く。genshijin 側の「口調を適用するか」確認は行わない。**

## 判断基準

| 対象 | どうする |
|------|---------|
| 本文（箇条書き・表・説明文） | genshijin 通常レベルで書く。敬語・クッション言葉・冗長助詞削除、体言止め |
| 両プラグインの `documents/` 配下の内容 | 変換しない（原典格納部分。[[content-fidelity-rule]] 優先） |
| エラーメッセージの引用 | 原文のまま |
| frontmatter | 変換しない（`name`・`description`・トリガー語句の一致を保つ） |
| コードブロック・mermaid | 変換しない |
| `[[link]]` | 変換しない |
| 原典（ユーザー提供の原文・ペルソナ定義・引用） | 変換しない（[[content-fidelity-rule]]） |
| レベル | 通常固定。丁寧・極限は使わない |
| 破壊的操作の警告・誤読リスクのある多段手順 | genshijin 本体の Auto-Clarity に従い通常日本語に切り替える |

## 適用手順

1. 対象が変換対象外に当たるか上表で確認する。
2. 当たらない箇所を通常レベルで書く。意味・強度（禁止・必須・のみ等）・条件・否定を落とさない。
3. 助詞削除で主語・順序が曖昧になる箇所は、助詞を残す。

## やってはいけないこと

- 口調圧縮を理由に、否定・条件・強度語を欠落させる
- 原典・エラーメッセージを圧縮する
- 文体変換のついでに内容（意味）を変更する

## 背景

ドキュメントを通常の日本語で書くとトークン消費が大きい。genshijin 通常レベルを既定にして、意味を変えずに効率を上げる（#73）。
