# 原典忠実性ルール

## 原則

ユーザー提供の原文（プロンプト文・ペルソナ定義・引用・仕様の原典など）をファイルへ格納・複製するとき、**原典を忠実に保つ**。勝手な補足・但し書き・婉曲化・要約で意味を弱めたり、ニュアンスを変えたりすることは禁止。

## やってはいけないこと

- 原文に無い但し書き・注記・免責を本文へ差し込む
- 「容赦なく」「何も隠すな」のような強い指示を、自分の判断で和らげる／条件を付ける
- 要約・言い換えで原典のトーンや強度を薄める

## 改善提案がある場合

原文に問題・改善余地を感じても、本文に混ぜ込まない。**別途ユーザーに提示し、採用可否の判断を仰ぐ**。採用が承認されたときだけ反映。

## 背景

`strict-mode` スキル作成時、ユーザー提供の Core Rule 原文に「率直さは判断局面に集中させる」という補足を独断で追加し、「原典重視なので但し書きは消しましょう」と撤回を指示された。原典の強度を勝手に弱める改変は意図に反する。
