# 原典忠実性ルール

## 原則

ユーザー提供原文（プロンプト文・ペルソナ定義・引用・仕様原典等）ファイル格納・複製時、**原典忠実保持**。無断補足・但し書き・婉曲化・要約で意味を弱めたりニュアンスを変えたりしない。

## やってはいけないこと

- 原文に無い但し書き・注記・免責 本文へ差込
- 「容赦なく」「何も隠すな」等 強い指示を 独断で和らげ／条件付与
- 要約・言い換えで 原典トーン・強度 希釈

## 改善提案がある場合

原文に問題・改善余地あっても 本文へ混ぜ込まない。**別途ユーザー提示→採否判断を仰ぐ**。採用承認時のみ反映。

## 背景

`strict-mode` スキル作成時、ユーザー提供 Core Rule 原文に「率直さは判断局面に集中させる」補足を独断追加→「原典重視なので但し書きは消しましょう」と撤回を指示された。原典強度の無断弱化改変 = 意図に反す。
