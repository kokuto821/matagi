# prompt-commonization

プロンプト（スキル・サブエージェント定義・AGENTS.md など）に複製された共通文言を検出し、共通文言ファイル（1ファイル1文言）へ集約して `@import` ブロックで参照する形に置き換えるスキル。

検出・適用・展開・検証はスクリプトで決定論的に行い、意味の同一性や抽出の粒度の判断はスキルが行う。置換はユーザーの承認後にのみ適用する。人間向け概要 = ここ、AI/ハーネス向け定義 = `SKILL.md`。

- `scripts/`: 検出・適用・展開・検証のスクリプトとテスト
- `reference/`: スクリプトの呼び出し仕様（`cli.md`）と計画 JSON の形式
- `evals/`: 評価ケース
